# Availability by surface

GeoBrix functions exist on up to four surfaces:

- SQL in a notebook or job session: `gbx_*` after `databricks.labs.gbx.register(spark)`.
- SQL in Unity Catalog: `<catalog>.<schema>.gbx_*` after `gbx.uc.install`.
- The Python API.
- Scala.

Python names are relative to the `databricks.labs.gbx` package. For example,
`gridx.bng.functions.bng_tessellate` is `from databricks.labs.gbx.gridx.bng import functions`.
