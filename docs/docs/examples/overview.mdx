# Examples Overview

This section provides practical examples of using GeoBrix for common geospatial workflows — end-to-end **notebook series** and **app** examples.

## Notebook Series

End-to-end, runnable notebook walkthroughs. Each links to the notebook source on GitHub.

| Series | What it covers |
|---|---|
| [EO Series](../notebooks/eo-series) | STAC discovery → band download → gridded (H3) raster tables → multi-band stacking, with Sentinel-2 over Alaska. |
| [Clipping — xView](../notebooks/xview) | Load high-resolution aerial GeoTIFFs and clip rasters per labeled object from the xView dataset. |
| [Wireless Coverage](../notebooks/wireless-coverage) | LiDAR → tower siting over San Francisco: build DSM / TIN-DTM / CHM surfaces from a USGS 3DEP LiDAR point cloud, index them to H3, and rank candidate tower sites with distributed H3 line-of-sight viewsheds (`h3_viewshed_towers`) — as a notebook series and as a production Lakeflow Declarative Pipeline (SDP) bundle. |
| [H3 Rasterize (DEM)](../notebooks/h3-rasterize) | Convert polygon isobands (elevation contours) into a pixel-aligned, multi-band H3 raster stack. |
| [Helios — Tiling to PMTiles](../notebooks/helios) | Four-notebook San Francisco series: vector, raster basemap, terrain scoring, and a sharded PMTiles mosaic. |
| [Vapor-Eyes — Permian Methane](../notebooks/vapor-eyes) | Screen a satellite methane signal over the Permian Basin down to the leaking operator. |
| [Orthomosaic Photogrammetry](../notebooks/orthomosaic) | Build a georeferenced orthomosaic from a drone image dataset: `exif_gbx` telemetry extraction, GSD estimation, sparse SfM, orthomosaic GeoTIFF, COG conversion, and PMTiles packaging — capped off with an optional GeoSAM segmentation step (`gbx.models`) that turns the published orthomosaic into georeferenced object polygons, in-notebook or via a served GPU endpoint. |
