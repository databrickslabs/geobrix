# Unity Catalog SQL examples

Try the GeoBrix [Unity Catalog functions](../api/uc-functions) with ready-made queries. Twelve SQL files cover every function by category, and each query uses small inputs and returns rows.

## Install the functions

Run `gbx.uc.install` once from an env 6 notebook or job. It creates the functions, and with `procedures=True` the procedures, in one schema. The [Unity Catalog functions](../api/uc-functions#install) page has the call and the Volume folder rules.

The examples use the catalog `geospatial_docs` and the schema `geobrix_uc`. Replace both names with your own, in the `USE` lines at the top of each file and in the table names of `11_procedures.sql`.

## Run the examples

1. Import the files into your workspace. Run `gbx:examples:uc-sql --upload` from a GeoBrix checkout, or copy the files from [`examples/uc-functions`](https://github.com/databrickslabs/geobrix/tree/main/examples/uc-functions).
2. Open `00_setup.sql` in the SQL editor and run it. It builds the sample tables the other files read.
3. Open any other file and run one statement at a time.

Each statement starts with a `-- cid:` comment that names it. The SQL editor ignores the comment, and the `gbx:examples:uc-sql` command uses it to run every file and check every result.

A statement that calls a GeoBrix Python function takes about 10 seconds on a SQL warehouse. A full run takes about 25 minutes.

## Check the whole set from a terminal

```bash
bash scripts/commands/gbx-examples-uc-sql.sh --profile <profile> --upload
```

The command runs the files in order on the warehouse. It fails when a statement errors or a query returns no rows. With `--upload` it also imports the files into `/Workspace/Users/<you>/geobrix/uc-function-examples/`.
