# GDAL raster drivers as provided

These are the raster drivers of the env wheel's GDAL build, with what each can do. `raster_gbx` and the raster writers use them. See the [legend and how to read the tables](../gdal-drivers#how-to-read-the-tables) on the parent page. GeoBrix turns off some drivers by default; they are not listed here, and the [opt-in drivers](../gdal-drivers#geobrix-opt-in-drivers) section names them.
