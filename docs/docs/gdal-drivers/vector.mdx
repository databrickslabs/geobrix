# GDAL vector drivers as provided

These are the vector drivers of the env wheel's GDAL build, with what each can do. `vector_gbx` and the vector writers use them. See the [legend and how to read the tables](../gdal-drivers#how-to-read-the-tables) on the parent page. GeoBrix turns off some drivers by default; they are not listed here, and the [opt-in drivers](./other#geobrix-opt-in-drivers) section names them.

## Available vector drivers: not tested with GeoBrix

These vector drivers are registered, and they may work with GeoBrix, but they are use-at-your-own-risk. `vector_gbx` reads a driver when you set its `driverName` option to the GDAL driver name. Plain GDAL, `from osgeo import gdal`, may suit them better than GeoBrix's distributed readers and writers.
