# File Lister — `file_gbx`

`file_gbx` lists files in a directory as **path-reference rows**. It reads no
raster or vector content — it emits one row per file with path, name,
extension, size, and modification time. Use it as the first step in a
preparation pipeline: list the files you want to process, then pipe those
references into a writer (e.g. `cog_gbx`) that opens and converts each one.

This is in contrast to `binaryFile` (which loads raw bytes) and the raster
readers (`raster_gbx`, `gtiff_gbx`) which decode rasters into the shared
`(source, tile)` schema. `file_gbx` is format-agnostic — it lists any file
type and never touches the file content.

:::note Lightweight only
`file_gbx` is a pure-Python lightweight DataSource. Register it with
`register(spark)` before use. There is no heavyweight GDAL counterpart.
:::

## Output schema

```
root
 |-- path:             string   — full absolute path to the file
 |-- name:             string   — filename including extension
 |-- extension:        string   — lowercase, no leading dot; NULL for files with no extension
 |-- size:             long     — file size in bytes
 |-- modificationTime: timestamp — last-modified time
```

No raster or vector content is loaded. The `path` values are the references
you pass to a subsequent writer.

## Options

| Option | Default | Description |
|--------|---------|-------------|
| `filterRegex` | `".*"` | Keep only files whose full path matches this regex. |
| `recursiveFileLookup` | `"false"` | When `true`, walk subdirectories recursively. |
