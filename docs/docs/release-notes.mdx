# Release Notes

:::info Current version: 0.6.0
:::

This page lists the key features of each release. Each series has a subpage with the full detail: [0.6.x](./release-notes-0-6) and [0.5.x and earlier](./release-notes-0-5-and-earlier).

To migrate old code, search for the baseline name in the [rename tables](./release-notes-0-5-and-earlier#general) for the 0.2 and 0.3 renames. Breaking changes are marked in each release below.

---

## v0.6.0

:::note
v0.6.0 is under development and not yet released.
:::

- **Breaking:** install one [env wheel per runtime family](./release-notes-0-6#env-wheels) (`+env5` or `+env6`). The 0.5.x light extras are gone, and [GeoBrix no longer installs PySpark](./release-notes-0-6#pyspark).
- **Breaking:** the [init-script install is removed](./release-notes-0-6#init-script). Install the env wheel and the JAR as cluster libraries, or use the DCS image.
- **Breaking:** the heavyweight `*_ogr` readers [return declared field types and NULLs](./release-notes-0-6#ogr-field-types), and [`gbx_file_write` defaults to `file_mode="fuse"`](./release-notes-0-6#file-write).
- **New:** incremental ingestion with [`read_paths` and `declare_ingest`](./release-notes-0-6#read-paths), [bad records set aside with `on_error`](./release-notes-0-6#on-error), and a [multi-format Lakeflow connector](./release-notes-0-6#lakeflow-connector).
- **New:** [transactional, versioned Zarr stores](./release-notes-0-6#zarr-stores) with [direct storage access](./release-notes-0-6#zarr-direct).
- **New:** a [Databricks Container Service image](./release-notes-0-6#dcs-image) that runs both tiers on dedicated clusters, and [GDAL 3.13.3, PROJ 9.9.0 and GEOS 3.15.0](./release-notes-0-6#native-stack) in the env wheel.
- **Changed:** [raster tessellation](./release-notes-0-6#tessellation-parity) matches across tiers and scales to scene-sized tiles, with one rule for [NoData, alpha and mask bands](./release-notes-0-6#nodata-alpha-mask).
- **Changed:** [large vector layers stream](./release-notes-0-6#vector-large-layers), [`file_gdb_gbx` writes on any compute](./release-notes-0-6#vector-writers), and [British National Grid transforms use OSTN15](./release-notes-0-6#proj-data).

## v0.5.2

- **New:** [`lidar_gbx` reader and writer](./release-notes-0-5-and-earlier#whats-new-in-v052) for LAS and LAZ point clouds, and DSM and CHM surface functions.
- **New:** `exif_gbx` reader for drone and camera EXIF and GPS data.
- **New:** `gbx.models` package with GeoSAM object segmentation on GPUs.
- **New:** `rst_viewshed_towers`, `h3_viewshed_towers`, `rst_land_cover` and `gbx_rst_percentile_stretch`, plus the Wireless Coverage example.
- **Changed:** ESRI and OGC coordinate-system authorities are preserved, and geometry-aware grid functions accept GeometryCollection inputs.

## v0.5.1

- **Breaking:** [raster-to-grid functions default to `coverage=complete`](./release-notes-0-5-and-earlier#whats-new-in-v051) and gain an `assignment` parameter. The `gbx_rst_*_rastertogridcount` functions return `DOUBLE`.
- **Breaking:** in the raster tessellate functions, `mode` is renamed `assignment`, a `coverage` parameter is added, and the two-argument default changes.
- **Changed:** a raster with no CRS is no longer warped to EPSG:27700 by the BNG raster-to-grid functions.
- **New:** raster-to-grid support for custom grids, `gbx_rst_combine*` and `gbx_rst_align_to`, and NetCDF multi-dimension options (`dimIndex`, `fanout`, `bandDim`).
- **New:** geometry-aware k-ring and k-loop functions across all grid families.

## v0.5.0

- **Breaking:** [`[light]` and `[light_all]` are removed](./release-notes-0-5-and-earlier#whats-new-in-v050). Install a runtime-pinned extra. `[earthdata]` and `[overture]` are opt-in extras.
- **Breaking:** lightweight raster readers default to virtual tiles. The tile struct widens to eight fields.
- **New:** the COG preparation lane (`file_gbx`, `cog_gbx`) with VRT mosaics for large rasters.
- **New:** CRS-string functions (`gbx_st_crs`, `gbx_rst_crs` and others) and `gbx.register_proj_grids`.
- **New:** VectorX validity, cleaning, antimeridian and coverage functions.

## v0.4.x

- **New in 0.4.0:** the [lightweight tier](./release-notes-0-5-and-earlier#whats-new-in-v040) (`pyrx`, `pygx`, `pyvx`) that needs no JAR and runs on Serverless.
- **New in 0.4.0:** vector tiles (`gbx_st_asmvt`), PMTiles output, quadbin and custom grids, terrain and spectral-index functions, TIN surface modelling, and STAC and visualization helpers.
- **Breaking in 0.4.0:** the grid explode functions return a lowercase `cellid` field, and slope and hillshade scale from the raster CRS by default.
- **New in 0.4.1:** the [`netcdf_gbx` reader](./release-notes-0-5-and-earlier#whats-new-in-v041) and methane-source downloaders for the Vapor-Eyes example.
- **Changed in 0.4.2:** [raster value reducers return `NULL`](./release-notes-0-5-and-earlier#whats-new-in-v042) for all-NoData bands.
- **New in 0.4.3:** [both-tier raster-grid parity](./release-notes-0-5-and-earlier#whats-new-in-v043), NetCDF readers and writer.

## v0.3.0

- **Fixed:** [`rst_clip` axis order](./release-notes-0-5-and-earlier#whats-new-in-v030) and `combineavg` / `derivedband` pixel functions.
- **Changed:** `tile.raster` bytes are always self-contained, and scalar arguments need no `f.lit(...)`.
- **New:** pre-built, hash-verified GDAL bundle.
