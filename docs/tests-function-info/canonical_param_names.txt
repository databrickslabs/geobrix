# canonical_param_names.txt
# FROZEN TARGET — post-rename canonical parameter names for GeoBrix registered functions.
# This file is the single source of truth for docs/scripts/check-param-names.py.
# Generated 2026-08-06. Do NOT hand-edit after the fixture is used as a CI baseline.
#
# Format: one function per line — name<TAB>arg_list
# Optional args use Style B: brackets wrap only the param name, comma outside: a, b, [c], [d]
#
# Exceptions documented here (guards expect these — do NOT "correct" them):
#   cellid    — deliberate single lowercase token (not cell_id, not cellId).
#               Matches the v1/v2 tile struct field, Mosaic convention, and product.
#               cellid1/cellid2 for bare-id pairs.
#   *_chip    — left_chip / right_chip / input_chip are STRUCT inputs {cellid, core, chip},
#               NOT scalar cell IDs. NEVER rename to cellid. See R4c ruling.
#   out_srid / out_crs — output-direction prefix on 9 output-producing rasterization functions.
#               Bare srid/crs would be ambiguous vs the input geometry's embedded CRS.
#   *_array   — points_array / breaklines_array are ArrayType inputs (not single geometries).
#               See N9 ruling. Do not drop the _array suffix.
#   [c1]/[c2] in gbx_rst_evi — EVI formula atmospheric correction coefficients (C1≈6.0,
#               C2≈7.5 MODIS-canonical), NOT cell IDs. Left as c1/c2 per domain semantics.
#   cellid — canonical single lowercase token for a bare BNG/quadbin cell id, on params AND
#               struct fields (matches the v1/v2 tile struct field, Databricks product, Mosaic).
#               cellid1/cellid2 for two-bare-id functions (bng_distance etc). The chip STRUCT
#               keeps left_chip/right_chip/input_chip (struct != scalar). quadbin_cellunion_agg
#               takes a scalar cell id (BIGINT, no chip struct) so it is cellid, not input_chip.
