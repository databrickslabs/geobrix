# GeoBrix Example Notebooks

Runnable, end-to-end example notebook series for [GeoBrix](https://databrickslabs.github.io/geobrix/). Each series lives in its own subdirectory here with its own `README.md`, and has a rendered walkthrough in the docs — narrative, diagrams, and a data-flow summary alongside the same notebook content. Download a series folder and import the numbered notebooks into your Databricks workspace to run it.

| Series | What it shows | Docs walkthrough |
|---|---|---|
| [`eo-series`](eo-series/) | A four-notebook Earth Observation series over Sentinel-2 L2A (Alaska): vector area-of-interest → STAC discovery (Microsoft Planetary Computer) → band download → gridded (H3) raster tables → multi-band stacking and clipping, on the lightweight tier (Serverless). | [Docs](https://databrickslabs.github.io/geobrix/docs/notebooks/eo-series) |
| [`xview`](xview/) | Loads high-resolution aerial GeoTIFFs from the xView Detection Challenge into Lakehouse tables and clips rasters to labeled GeoJSON objects, using RasterX with the built-in Spatial SQL functions. | [Docs](https://databrickslabs.github.io/geobrix/docs/notebooks/xview) |
| [`wireless-coverage`](wireless-coverage/) | Builds the elevation/surface data foundation for wireless-coverage analysis from a USGS 3DEP LiDAR point cloud over San Francisco: binned DSM/DTM/CHM (`rst_binpoints_agg`, `rst_chm`) plus a binned-vs-TIN bare earth (`rst_dtmfromgeoms_agg`). | [Docs](https://databrickslabs.github.io/geobrix/docs/notebooks/wireless-coverage) |
| [`h3-rasterize`](h3-rasterize/) | A DEM extra for the Wireless Coverage series: downloads a USGS 3DEP seamless (10 m) DEM, clips it to an Overture Maps land mask, extracts elevation isobands, and indexes them with Databricks product H3 into a multi-band raster stack. | [Docs](https://databrickslabs.github.io/geobrix/docs/notebooks/h3-rasterize) |
| [`helios`](helios/) | A four-notebook solar site-selection series that turns one San Francisco bounding box into self-contained PMTiles archives — candidate rooftops (vector), aerial basemap (raster), and terrain slope/aspect/hillshade scoring (elevation) — then reshards a layer into a distributed multi-archive PMTiles mosaic + catalog for web-scale delivery. | [Docs](https://databrickslabs.github.io/geobrix/docs/notebooks/helios) |
| [`vapor-eyes`](vapor-eyes/) | Works a satellite methane signal over the Permian Basin from a wide-area screen down to the leaking operator, reading Sentinel-5P (TROPOMI) and EMIT plume data. Ships in two flavors: a production-ready Lakeflow pipeline and an interactive notebook series. | [Docs](https://databrickslabs.github.io/geobrix/docs/notebooks/vapor-eyes) |
| [`orthomosaic`](orthomosaic/) | Drone imagery to a georeferenced orthomosaic: distributed sparse SfM plus an optional GPU dense MVS pass with `pycolmap`, published via color-correction → COG → PMTiles, then (optionally) GeoSAM instance-object polygons and an `rst_land_cover` region map, with the object model served behind a Unity Gateway GPU Model Serving endpoint. | [Docs](https://databrickslabs.github.io/geobrix/docs/notebooks/orthomosaic) |

See the [Examples overview](https://databrickslabs.github.io/geobrix/docs/examples/overview) docs page for the full catalog, including the [Genie Map](https://databrickslabs.github.io/geobrix/docs/examples/genie-map) app example.
