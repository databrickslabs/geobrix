# geobrix-0.6.0+env5 default dependencies: DBR 17.3, DBR 18, Serverless environment 5, Lakeflow
# CURRENT. The env wheel's unmarked Requires-Dist is exactly this file (gbx:build:wheel checks it).
# rasterio, pyogrio, pyproj, shapely and netCDF4 are not here: the wheel carries them, built against
# its own GDAL (_vendor/<arch>), and so rio-tiler, morecantile and mapbox-vector-tile (vendor-pure.txt),
# and GDAL's own osgeo and osgeo_utils from that GDAL. rio-cogeo and xarray-spatial are dropped:
# GDAL's COG driver and GDALViewshedGenerate do their work.

# The runtime's preinstalled versions as the floor, the next minor as the cap: these move nothing.
# These are FROZEN-BASE caps, deliberate: this wheel targets frozen runtime bases (DBR 17.3, DBR 18, Serverless
# environment 5), so a cap cannot downgrade the runtime's numpy, pandas, pyarrow, scipy, protobuf or urllib3, and
# it stops a transitive requirement from upgrading one. (The extras follow another rule: a package the runtimes
# preinstall gets a floor only there; see gbx:build:wheel.)
# (DBR 17.3 ships pyarrow 19.0.1, DBR 18 and env 5 ship 21.0.0.)
numpy>=2.1.3,<2.2
pandas>=2.2.3,<2.3
pyarrow>=19.0.1,<22
scipy>=1.15.1,<1.16
protobuf>=5.26.1,<6
urllib3<2.4
# What the core install does move (gbx:versions:audit --install-moves lists these and fails on any other move), each
# to the newest release that meets the floor, as pip upgrades an installed package that does not:
# - typing_extensions 4.12.2 -> 4.13 or later: PEP 728 TypedDict(extra_items=...), which rio-tiler 9 uses, works
#   from 4.13.0;
# - idna 3.7 -> 3.18 or later, anyio 4.6.2 / 4.7.0 -> 4.10 or later, h11 0.14.0 -> 0.16 or later (DBR 17.3): httpx2
#   2.12 and later (below) need them; earlier httpx2 releases have two HIGH advisories, and h11 0.16 is itself the
#   fix for CVE-2025-43859;
# - httpcore 1.0.2 -> 1.0.9 or later (DBR 17.3 only): its httpcore 1.0.2 requires h11<0.15, so the h11 move would
#   leave it broken; 1.0.9 is the release that accepts the fixed h11. DBR 18 and environment 5 already have 1.0.9.
typing_extensions>=4.13
httpcore>=1.0.9
